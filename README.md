# Countdown Timer

A simple terminal countdown timer written in Python.
The program asks for a time in HH:MM:SS format, validates the input,
and counts down, printing one line every second.

## How to run

python countdown.py

## Example

Enter time (HH:MM:SS): 00:00:03
00:00:03
00:00:02
00:00:01
00:00:00
Time's up!
